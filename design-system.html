01 — Overall Strategy

Beyond Color Swaps

Each theme must feel like a completely different product made for a different person — not the same app painted differently. Differentiation happens across five axes: typography personality, border radius language, icon weight & style, spacing density, and shadow/surface behavior.

Common Foundation

Shared semantic tokens keep the codebase maintainable. Every component references --color-bg, --color-accent, --radius-card etc. Theme switching is a single data-theme attribute on <html>.

🌸
Rosé Journal
Soft · Warm · Personal
  • Rounded-everything: cards, chips, FAB
  • Serif accent in logo (Fraunces)
  • Dashed borders as dividers
  • Gradient-filled buttons & FAB
  • Warm pink/lavender palette
  • High border-radius (20-28px cards)
  • Outlined icons, lighter weight
🌑
Midnight Focus
Sharp · Dense · Precise
  • Near-zero border radius (4-6px)
  • Monospace type accent (Space Grotesk)
  • Left-border accents instead of chips
  • Ghost / outlined buttons only
  • Deep navy/indigo on black
  • High info density, tight spacing
  • Thin stroke icons (1.5px)
💼
Workday Minimal
Clean · Structured · Reliable
  • Underline tabs (not pill tabs)
  • Instrument Sans — neutral, legible
  • White backgrounds, 1px dividers
  • Flat buttons, no gradients
  • Sky blue + neutral grays
  • Medium radius (8px)
  • Standard stroke icons (1.75px)
⚡
Campus Fresh
Bold · Graphic · Energetic
  • Hard shadow (offset box-shadow)
  • Syne — ultra-bold display font
  • 2px dark borders on everything
  • Lime green + black neo-brutalism
  • Mixed radius (14px cards, pill chips)
  • Bold stroke icons (2.5px)
  • High contrast, saturated color

05 — Do / Don't Rules
✓ Do — Rosé Journal
Dashed borders as section dividers
Gradient fill on primary buttons & FAB
Pill-shaped chips (border-radius: 100px)
Soft box-shadows with pink tint
Outlined Lucide icons, stroke-width: 1.75
✕ Don't — Rosé Journal
Sharp corners anywhere in the UI
Dark or high-contrast backgrounds
Uppercase text labels
Flat/ghost buttons as primary CTA
Dense, information-heavy layouts
✓ Do — Midnight Focus
Left-border accent lines on cards
Uppercase + letter-spacing on labels
Ghost buttons with thin border
Tight spacing — maximize content density
Monochrome icons, thin stroke (1.5px)
✕ Don't — Midnight Focus
Rounded cards (> 8px radius)
Gradients or colorful fills
Emoji as UI elements
Bright backgrounds or light mode
Multiple accent colors simultaneously
✓ Do — Workday Minimal
Underline tabs (not pill/capsule tabs)
1px solid borders, no shadows
Flat filled primary button
Consistent 8px border-radius
White card surfaces on gray background
✕ Don't — Workday Minimal
Gradients or decorative elements
Bold or display fonts
Pill-shaped components
Multiple accent colors or heavy shadows
Playful or expressive iconography
✓ Do — Campus Fresh
2px dark border on all components
Offset box-shadow (3px 3px 0 #1a1a1a)
Bold weight on all interactive elements
Lime green + yellow as accent pair
Heavy icon stroke (2.5px)
✕ Don't — Campus Fresh
Thin, delicate strokes or soft shadows
Muted or desaturated color palette
Small or subtle typography
Light, airy spacing
Serif or elegant fonts

08 — Final Recommendation
Default Theme
💼 Workday Minimal

가장 넓은 유저베이스에 무난하게 작동합니다. 가독성 최우선 + 성별·연령 중립 → 첫 인상에서 거부감이 없습니다. 온보딩에서 선택하지 않은 유저의 기본값으로 적합.
